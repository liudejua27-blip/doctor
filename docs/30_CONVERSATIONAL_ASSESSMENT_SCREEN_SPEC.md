> **评审边界。**本文件把既有规范翻译为未来“身体位置 → 情境 → 安全分流 → 一次一问 → 事实复核”的界面交付语言，供产品、iOS、无障碍、临床安全和 QA 共同评审。它不新增状态字段、API、Schema、真实 Agent、真实健康数据处理、内容库或正式写入能力；也不表示任何页面、AI、资料读取、行动、保存或 3D 体验已经实现或获准上线。

## 1. 目的、范围与非目标

### 1.1 要解决的界面问题

用户首先需要表达“我感觉在哪里不舒服”，随后才需要在当前训练、久坐工作或日常活动情境下补足可比较的事实。界面不能把这件事退化为一个泛聊天框，也不能让 3D 模型、来源资料或 AI 文字越过事实确认和安全分流。

本说明覆盖从“记录这次不适”进入到第二次保存批准前的未来评估体验，以及与其互斥的安全、手动和降级替代界面。报告、分享、复查和档案详情沿用 [UX-01](02_UX_AND_USER_FLOWS.md)、[PROD-01](01_PRODUCT_REQUIREMENTS.md) 的真源，不在这里重新设计。

### 1.2 不改变的上位事实

| 事实 | 本界面如何遵守 |
|---|---|
| 2D/3D 仅表达用户主观位置 | 所有位置标题使用“你感觉在这里”；不显示组织、病因、损伤或诊断名称。 |
| 安全先于普通 Agent | 客户端只呈现服务端已判定的下一界面；不得从网络状态、用户选择或本地聊天文本推断可进入普通对话。 |
| AI 候选不是事实 | AI 整理的内容始终带“待你确认”，只在用户复核后进入后续保存流程。 |
| 可选资料默认关闭 | “仅使用本次记录”是可完成主链的默认选项；已授权、已读取和实际进入模型上下文必须分别显示。 |
| R2 不进入普通对话 | R2 只显示固定的专业评估准备和事实沟通路径，不显示普通自我管理、训练调整、动作、营养或聊天。 |
| 行动只来自审核内容 | 行动区域只有在上位安全、事实、内容和版本条件均满足时才可出现；界面不得以占位建议填空。 |
| 正式保存需要两次不同确认 | “复核事实”与“批准并保存”是两个不同动作；前者不得显示为已保存，后者没有权威读回不得显示成功。 |

### 1.3 非目标

- 不把本说明当作 API、字段、QuestionPolicy、资料收据或内容库的定义；这些仍由 ADR-0019 及上位契约在获批后定义。
- 不定义任何红旗题目、医学阈值、动作、训练调整、饮食、补剂、药物、剂量或专业帮助文案。
- 不设计“AI 医生”、开放医疗聊天、病名结论、恢复时间、复出许可或自动保存。
- 不把当前 P0 SwiftUI 壳、Simulator Host、候选 3D 人体或原型测试描述为本说明中的生产能力。

## 3. 体验骨架与始终可见的信息层级

### 3.1 明亮中文体验方向

界面沿用 FEAT-COMP-01/UX-01 的方向：暖白或雾蓝底色、深色高对比中文文字、克制的蓝色选中态，以及中性半透明人体作为**位置事实锚点**。3D 只用于表达与编辑位置；它不遮挡当前问题、资料边界、安全 CTA 或保存动作。紧急/专业帮助的显著性必须由 SAFE-01 的语义、文字和优先级决定，不能仅靠品牌色或动效。

对话区采用单条问题卡而非连续闲聊气泡流：一条清楚的问题、可聚焦的快捷选项、文字/语音补充入口和“说不清”出口。AI 的温度来自清晰、尊重和可退出的交互，不来自拟人医疗角色、卡通形象或“我已了解你全部身体状况”等暗示。

### 3.2 共同事实条

在 CA-02 之后，非安全替代页面顶部显示一条可展开的“本次身体记录”事实条。它只展示当前服务端/草稿已允许展示的信息，不做本地推断。

| 区块 | 可见文案与来源 | 可执行操作 | 不得显示 |
|---|---|---|---|
| 位置 | “你感觉在：左侧膝部前方”等用户确认或待复核的位置；多个位置显示数量与编辑入口 | 返回位置编辑；切换 2D/列表；3D 可用时仅作为同一位置编辑方式 | 肌肉、神经、受损组织、病因或“精准诊断” |
| 本次情境 | “训练/运动后”“久坐/工作后”“日常活动”或“说不清”；同时选中时逐项展示 | 查看或更改本次选择；更改后按上位规范使后续结果重新检查 | “主要病因”“根本原因”或自动长期档案标签 |
| 待补充 | 仅列出当前流程明确需要的事实组，如“时间”“功能影响” | 进入对应的结构化编辑或当前题目 | 将未回答默认渲染成否定、0 分或低风险 |
| 资料范围 | 默认“仅使用本次记录”；若可选来源存在，仅显示实际授权/使用的最小摘要 | 打开“本次经授权参考”详情；撤回/修改范围走上位同意流程 | “已读取全部资料”“长期记忆已启用”或原始健康正文 |

事实条在 R0/R1/R2、未解决安全、`manual`、`unsupported` 或 `degraded` 分支中由相应替代页决定是否显示和显示多少；它不得压过安全行动或制造普通 Agent 已运行的印象。

### 3.3 统一来源与不确定性标签

所有界面复用以下已有语义。颜色、图标或位置可以辅助，但文字标签必须保留。

| 用户可见标签 | 何时出现 | 必须能看见的最小信息 |
|---|---|---|
| **你告诉我的** | 用户直接输入或已复核的结构化事实 | 事实内容、可修改入口、确认/待确认状态 |
| **AI 整理，待你确认** | 仅限 AI 返回的候选 | 候选内容、接受/修改/删除；不得与确认事实混排为同一状态 |
| **本次经授权参考** | 服务端声明某项可选资料实际用于本轮 | 资料类别、来源的脱敏引用、时间范围、用途、实际使用结果；可打开完整收据 |
| **未使用 / 你已拒绝 / 没有可用资料 / 已过期 / 策略未允许** | 资料收据给出相应结果 | 真实状态与不阻断核心记录的说明；不得解释为用户“没有问题” |
| **仍不确定** | 用户选择“说不清”、未回答或系统明确无法确认 | 保留未知的事实组；不得强行补写、静默删除或转为否定 |
| **位置只表示你的感觉位置** | 位置选择、事实复核、报告前的关键位置回显 | 该位置是用户主观表达，不代表受损组织或病因 |
| **AI 辅助，不作诊断** | AI、行动、专业帮助或摘要相关屏幕 | 能力边界；不替代安全行动或固定风险说明 |

## 4. 互斥的安全替代规则

屏幕不是根据“聊天是否好看”选择，而是根据服务端已经完成的安全、覆盖、同意、验证和内容判定选择。下表不定义任何新状态，也不要求客户端自行计算；它只规定不同结果**不得同时呈现**。

| 服务端已决定的分支 | 用户首先看到的替代界面 | 必须抑制的界面/内容 | 返回或继续规则 |
|---|---|---|---|
| 必要安全信息未解决 | CA-03 安全确认 | CA-04 普通问题、CA-06 R3 行动预览、任何“分析完成”文案 | 仅可回答审核安全题、修改相关事实、保存未确认草稿或退出；修改后必须重新检查 |
| R0 紧急行动 | CA-03A 紧急帮助 | 普通对话、行动卡、训练/工作调整、营养、复查建议、营销 | 紧急 CTA 始终优先；仅在上位条件允许且行动已展示后可弱化进入事实留档 |
| R1 当日/紧急专业评估 | CA-03B 专业帮助 | 普通对话、等待/试动作/营养、普通行动 | 专业帮助入口持续置顶；事实复核只能作为次级路径 |
| R2 专业评估准备 | CA-07 固定专业准备 | CA-04 普通 Agent、CA-06 普通行动、动作、训练调整、营养 | 只可整理既有事实、准备沟通摘要或按既有边界复核；不得通过返回重进普通聊天 |
| R3、完整、受支持且普通路径获准 | CA-04 一次一问；满足内容条件后才可 CA-06 | R0/R1/R2 文案混入普通卡；病名、处方、未审核建议 | 修改位置、感觉、情境、资料范围或安全相关事实后，旧问题/行动预览失效并回到重新检查的合适位置 |
| 用户未授权可选云端 AI，但确定性安全与验证完整并允许手动路径 | CA-08A 手动记录 | AI 候选、AI 行动、Provider/模型已运行的暗示 | 允许固定结构化录入和后续事实复核；必须明确“未使用 AI 分析” |
| 规则、必要验证、内容、映射或兼容性无法安全证明；或无法安全转入手动路径 | CA-08B 降级模式 | 普通对话、个体行动、正式保存承诺、缓存个体建议 | 保留未确认草稿、固定安全入口、2D/列表、重试/稍后继续；恢复后必须重新检查 |
| 场景/人群/区域未被当前审核范围覆盖 | CA-08C 超范围说明 | 假装普通分析、普通行动、诊断性解释 | 保留适用的安全入口和事实记录路径；不利用“未覆盖”降低安全要求 |

## 5. 页面级交付说明

### CA-00 入口、继续草稿与新建确认

| 项目 | 交付要求 |
|---|---|
| 用户目标 | 决定开始一条新的“记录这次不适”，或继续当前会话中的未确认草稿。 |
| 视觉层级 | 1) `记录这次不适` 主按钮；2) 运动后、久坐/工作后、日常活动仅作为入口提示，不能写成已选情境；3) 有草稿时，先出现“继续这条草稿”和“新建一条记录”。 |
| 可见数据/标签 | 草稿只称“当前会话中的未确认草稿”；不得显示“已保存”、伪造最后保存时间或正式 Episode。 |
| 允许操作 | 继续同一草稿；在明确二次确认后放弃未确认草稿并新建；进入公共安全帮助。 |
| 返回/取消 | 返回 Tab 不丢草稿。取消“新建”保持原草稿、原位置和原未确认事实，不重置 UUID 或切换到另一条记录。 |
| 无障碍与动效 | 主按钮、继续/新建都具有完整 VoiceOver 标签和 ≥44 pt 目标；大字体纵向堆叠；无进入动画依赖。 |
| 加载/离线/失败 | 不需要网络才能呈现入口；若本地草稿能力尚未可用，不得捏造“可恢复”，只显示实际可用的当前会话行为。 |

### CA-01 位置表达：2D、3D 与部位列表

| 项目 | 交付要求 |
|---|---|
| 用户目标 | 用区域或精确点表达“我感觉在这里”，并确认侧别/表面。 |
| 视觉层级 | 1) 标题“哪里不舒服”；2) 位置只表示感觉位置的短提示；3) 2D/3D 切换与部位列表入口同层可达；4) 当前选中的位置摘要；5) 添加/继续。 |
| 可见数据/标签 | 已选 Marker 的通俗部位、侧别、表面、区域/精确点和“未确认”状态；不得显示感觉、强度、诱因、AI 推断或安全等级。 |
| 允许操作 | 选择区域/针点、编辑/删除草稿 Marker、旋转/缩放/四视角、切到 2D 或可搜索列表。图形点击与列表必须产生同一规范位置语义。 |
| 返回/取消 | 取消某个位置 Inspector 只撤销当前未提交的位置编辑；离开页面保留已存在草稿。删除位置后，后续感觉/安全/普通分析/审批资格按上位规范重新复核，不在本页推测结果。 |
| 无障碍与动效 | VoiceOver 可用“搜索部位 → 左右 → 前后/表面 → 确认”完成同一任务；RealityKit Canvas 不是唯一输入；Dynamic Type 不遮挡继续按钮；Reduce Motion 下相机直接切换、无持续旋转/飞行。 |
| 加载/离线/失败 | 3D 资产 gate、性能或碰撞失败时，不显示健康含义错误；立即提供 2D/列表并保留同一草稿。离线不暗示云端分析已完成。 |

### CA-02 本次情境与资料范围 Sheet

| 项目 | 交付要求 |
|---|---|
| 用户目标 | 说明本次更接近训练/运动、久坐/工作、日常活动还是说不清，并决定是否仍只使用本次记录。 |
| 视觉层级 | 1) 标题“这次更像在什么情况下出现？”；2) 情境多选区域；3) 简短解释“只用于本次问题排序，不代表原因”；4) 资料范围；5) 主按钮“继续”。 |
| 可见数据/标签 | 默认清楚显示“仅使用本次记录”。可选来源若在未来获准显示，分别展示类别、用途、时间范围和授权入口；不以“AI 更懂你”为卖点。 |
| 允许操作 | 选择/移除现有上位规范中的情境；保留多个非 `unknown` 情境；选择“说不清”；主动选择某可选来源；打开资料说明。多位置/多感觉时，允许在上位能力可用后选择本轮分析焦点。 |
| 返回/取消 | 关闭 Sheet 等价于保留“仅使用本次记录”与“说不清”的保守路径；不得默认开启历史、HealthKit、上传、长期记忆或第三方模型。已进入后续流程后改变情境、位置/感觉关联或资料范围，必须说明其会使旧问题/行动预览重新检查。 |
| 无障碍与动效 | 每项选择控件朗读已选/未选及“本次、可撤回”语义；大字体中选项单列；Sheet 不依赖拖拽关闭；Reduce Motion 不以选中飞入动画确认状态。 |
| 加载/离线/失败 | 若可选来源/同意服务不可用，默认显示“仅使用本次记录”，且不得把不可用误写成用户拒绝或无数据。Sheet 本身不读取资料，也不得宣称已被模型使用。 |

### CA-03 安全确认与高优先级替代页

| 项目 | 交付要求 |
|---|---|
| 用户目标 | 回答当前经审核、改变安全分流所必需的问题，或在 R0/R1 时首先看到需要采取的固定行动。 |
| 视觉层级 | 未解决安全时：当前一条审核问题、明确的答案选项和“不确定”含义；R0/R1 时：固定行动 CTA、为何需要行动的非诊断说明、公共帮助入口、AI 边界。 |
| 可见数据/标签 | 仅呈现已允许展示的用户报告事实和固定审核文本；“当前信息未命中规则”不得写成“安全”或继续训练许可。 |
| 允许操作 | 回答当前安全题、修改相关事实、查看固定帮助入口；R0/R1 行动完整呈现后，只有在上位条件满足时可进入弱化的事实留档。 |
| 返回/取消 | 安全 CTA 在后续允许的留档/复核页面持续置顶；用户可以退出 App，但 UI 不得用返回绕过或隐藏该行动。安全题答案或相关事实变动必须重新检查。 |
| 无障碍与动效 | R0/R1 CTA 是首个 VoiceOver 可达主要动作；文字、图标、形状共同表达优先级；大字体下 CTA 不被人体/Sheet 遮挡；不以闪烁、倒计时或震动作为唯一提示。 |
| 加载/离线/失败 | 安全规则、版本或必要验证不可用时不得切入普通聊天；进入 CA-08B，并保留最小安全入口。 |

### CA-04 R3 一次一问的 AI 身体助手

| 项目 | 交付要求 |
|---|---|
| 用户目标 | 在当前安全、覆盖和资料边界均已满足时，只回答一条高价值问题，或选择“说不清”。 |
| 视觉层级 | 1) 事实条（位置/情境/待补充）；2) 单条问题卡；3) 大面积快捷选项；4) “说不清”；5) 文字/语音补充；6) 本次经授权参考；7) 修改事实入口。不能在同屏展开多个问题。 |
| 可见数据/标签 | 问题说明只显示由服务端 `QuestionPlan` 已提供的用户可见理由；任何 AI 提取结果标为“AI 整理，待你确认”。资料区显示实际资料使用结果而非授权总览。 |
| 允许操作 | 选择已审核选项、输入/语音补充、选择“不确定”、打开来源收据、修改位置/详情、暂停并保留未确认草稿。客户端不得本地挑题、重排问题、生成安全题或把自由文本直接变成确认事实。 |
| 返回/取消 | 返回修改位置/详情后，旧普通问题、候选和行动预览按上位规则失效；关闭会话只保留未确认草稿，不自动写入。若服务端返回下一题，旧题不得覆盖新 revision。 |
| 无障碍与动效 | 焦点顺序为事实条摘要 → 当前问题 → 选项 → 不确定 → 补充 → 来源 → 修改；选项用原生可聚焦控件；Dynamic Type 下卡片纵向展开；Reduce Motion 下不以“正在思考”脉冲表达处理中。 |
| 加载/离线/失败 | 请求中仅显示“正在整理本次记录”，不得显示预设 AI 建议。Provider 无法使用时，只有上位条件允许才转 CA-08A；规则/验证/内容不可用或无法安全手动时转 CA-08B。 |

### CA-05 事实复核：把候选与用户事实分开

| 项目 | 交付要求 |
|---|---|
| 用户目标 | 逐组确认、修改、删除或保留未知事实，并清楚知道尚未保存。 |
| 视觉层级 | 1) 标题“复核这次身体记录”；2) 你告诉我的；3) AI 整理，待你确认；4) 本次经授权参考；5) 仍不确定；6) 主按钮“复核完成，继续保存”；7) “稍后继续”。 |
| 可见数据/标签 | 位置、感觉、强度、时间、因素、功能影响和来源按既有事实组呈现；每项体现来源和确认状态。资料不展示原始全文；行动预览若可展示，与事实区视觉分离。 |
| 允许操作 | 接受/修改/删除 AI 候选；修改用户事实；查看资料收据；返回位置/详情。主按钮只能请求创建待批准意图，不能乐观显示“已保存”。 |
| 返回/取消 | 返回编辑时保留目前草稿；取消/稍后继续不丢草稿。版本冲突、资料撤回、位置/情境/安全修改或内容变化时，旧复核/预览失效，显示差异并要求重新复核。 |
| 无障碍与动效 | 每一项以“来源 + 内容 + 状态 + 操作”顺序朗读；删除/修改不只用滑动手势；大字体下操作不与内容同一水平行强塞；不以卡片翻转表现确认。 |
| 加载/离线/失败 | 若无法请求待批准意图，保留草稿和安全入口；不得显示保存完成。离线只显示实际上位规范允许的未确认草稿行为。 |

### CA-06 R3 审核行动预览（条件性出现）

| 项目 | 交付要求 |
|---|---|
| 用户目标 | 在事实复核后理解“下一步为何出现、何时停止/升级”，而不是接受一个未解释的 AI 建议。 |
| 视觉层级 | 1) 当前非诊断性行动层级；2) 基于哪些确认事实与本次情境；3) 最多由审核内容提供的行动类别；4) 每项停止/升级条件；5) 内容/版本和不确定性入口。 |
| 可见数据/标签 | 仅显示由服务端有效 `ActionPlanPreview` 提供的已审核内容及其依据；“可能相关情境，不代表原因”必须可见。没有完整匹配内容时，不显示空白行动卡或模型临时补写。 |
| 允许操作 | 展开“为什么出现”“何时停止/升级”“本次经授权参考”；返回修改事实；进入后续复核/保存流程。用户不能编辑内容文本、把预览另存为正式行动或把它当处方。 |
| 返回/取消 | 任何位置/感觉关联、情境、资料范围、确认事实、安全、规则或内容版本改变，都立即隐藏旧预览并回到重新检查/复核；取消预览不影响未确认事实。 |
| 无障碍与动效 | 每项按“行动类别 → 适用理由 → 停止/升级 → 来源”朗读；用文字而非颜色区分重要性；Dynamic Type 下每项完整纵向排列；无自动展开/轮播。 |
| 加载/离线/失败 | 内容未匹配、版本过期、收据失效或服务不可用时 fail closed，不用通用建议替代；引导回事实、复查或专业帮助的上位路径。 |

### CA-07 R2 固定专业评估准备

| 项目 | 交付要求 |
|---|---|
| 用户目标 | 清楚看到尽快专业评估的优先级，并整理可供沟通的已知事实。 |
| 视觉层级 | 1) 固定专业帮助/预约准备 CTA；2) 已知事实摘要；3) 升级条件；4) 弱化的“复核事实”或“准备沟通摘要”入口。 |
| 可见数据/标签 | 只显示用户已报告事实、固定审核准备文本、未知项与 AI 边界；不把 R2 表述成诊断、治疗建议或“自我管理方案”。 |
| 允许操作 | 查看固定专业帮助、整理/复核事实、按上位条件准备沟通摘要、退出。 |
| 返回/取消 | 专业帮助入口在整个 R2 路径持续可见；返回编辑会触发重新检查，不能重新进入 CA-04/CA-06。 |
| 无障碍与动效 | 专业 CTA 为首要焦点；不靠红色或动画表达优先级；大字体下摘要和 CTA 保持完整可达。 |
| 加载/离线/失败 | 固定路径不依赖 Provider；若规则/固定内容不能验证，转 CA-08B，而不是展示普通聊天或旧行动。 |

### CA-08A 手动记录与 CA-08B 降级模式

| 项目 | CA-08A 手动记录 | CA-08B 降级模式 |
|---|---|---|
| 进入条件 | 只由服务端在确定性安全、映射、同意和验证完整且允许手动时呈现。 | 规则、必要验证、内容、映射、兼容性或安全手动前置无法证明；也用于不能安全回退的失败。 |
| 用户目标 | 不使用 AI 也完成结构化事实记录和后续复核。 | 保留已输入内容，知道普通分析暂不可完成，并取得固定安全入口。 |
| 视觉层级 | “未使用 AI 分析”说明 → 固定结构化字段 → 事实复核入口。 | “暂时无法完成普通分析”说明 → 已保留的未确认草稿 → 安全/2D/列表/重试/稍后继续。 |
| 禁止内容 | AI 候选、AI 个体解释、普通 ActionPlan、Provider 已运行暗示。 | AI/普通行动/正式保存承诺、缓存个体建议、诊断或“系统异常表示没有问题”。 |
| 返回/取消 | 退出保留未确认草稿；后续仍按两阶段确认，且不会把手动记录标为 AI 分析。 | 退出/重试都不清空草稿；恢复后必须重跑需要的安全和验证，不复用旧结果。 |
| 无障碍与动效 | 使用与 CA-05 同等的原生结构化控件和来源标签。 | 失败原因、数据是否保存、可做/不可做事项可由 VoiceOver 一次理解；不使用无限加载动画。 |
| 离线/失败 | 不因 Provider 缺失降级为假 AI；只有完整手动前置存在时可继续。 | 离线、规则不可用或版本不兼容不得被静默视为手动可保存；保守保留草稿并提供紧急入口。 |

### CA-09 第二次保存批准（与结果页的交接）

| 项目 | 交付要求 |
|---|---|
| 用户目标 | 明确决定是否批准创建一条正式身体信号事件。 |
| 视觉层级 | 标题“确认保存这次身体记录” → 服务端摘要 → 将创建什么 → 当前安全/资料范围/期限 → `批准并保存` → `返回修改` → `拒绝保存`。 |
| 可见数据/标签 | 必须清楚显示这是第二次确认；只显示服务端权威摘要、版本、期限与来源范围，不展示隐藏推理或扩展资料。 |
| 允许操作 | 批准、拒绝、返回修改；若要求近期认证，完成后回到同一摘要。 |
| 返回/取消 | 拒绝回 CA-05；到期、同意变化、草稿 revision 或安全基线变化时显示“审批已失效”，重新复核。网络 pending/executing 不得显示“已保存”。 |
| 无障碍与动效 | 批准的后果在按钮前完整朗读；拒绝并非视觉弱到不可达；动态字体下不截断事件数量、期限或安全摘要。 |
| 加载/离线/失败 | 没有服务端权威 read-back 只能显示恢复/重试状态；失败保留未确认草稿和安全入口。已执行后才由 UX-01 的结果/复查/报告流程接手。 |

## 6. 共同无障碍、隐私与故障要求

| 维度 | 所有 CA 页面必须满足 |
|---|---|
| VoiceOver / Switch Control / 键盘 | 图形不是唯一输入；当前页面唯一主要决定、事实来源、当前模式、可用/不可用操作和安全行动的朗读顺序明确。所有卡片操作有原生可聚焦替代。 |
| Dynamic Type | 关键标题、来源、停止/升级条件、审批后果和按钮不固定高度；窄屏/超大字号时卡片、资料条和 CTA 改为垂直布局。 |
| Reduce Motion | 相机切换无飞行、扫描或持续旋转；加载使用静态进度说明；选中/确认不依赖动画。 |
| 颜色与对比度 | 安全、来源、已选/未选、候选/确认、错误/成功均有文字与图标/形状；紧急与专业 CTA 遵循语义色和高对比度要求。 |
| 隐私最小化 | 任务切换器、锁屏、普通日志、崩溃与产品分析不显示原话、精确身体位置、感觉、强度、资料正文或 Provider 上下文。资料收据只显示最小脱敏引用。 |
| 异步一致性 | 页面只消费当前 revision 的服务端结果；离开页面时取消无意义请求；旧响应不能覆盖位置/情境/事实已经变化后的界面。 |
| 草稿保护 | 错误、切换 2D/3D、取消 Sheet、Provider 失败或关闭普通对话不得静默清空未确认草稿。正式 Event 与草稿的状态、文案和结果页必须区分。 |

## 7. 六个评审走查场景

这些是设计和测试走查，不是合成医学规则、内容或已实施行为。具体问题、规则结果、行动内容和资料收据仅能来自后续获批的上位能力。

### W-01 跑步后不适，R3 普通路径

1. 用户从 CA-00 选择“记录这次不适”，在 CA-01 标出一个主观位置；界面不称其为组织损伤。
2. 在 CA-02 选择训练/运动情境并保留“仅使用本次记录”。
3. CA-03 的必要安全确认完整后，服务端允许 R3 普通路径；界面只能进入 CA-04，不能显示“已安全”或已生成建议。
4. CA-04 显示一条已审核 `QuestionPlan` 对应问题和“不确定”出口；用户补充后，任何提取结果进入 CA-05 的“AI 整理，待你确认”。
5. 仅在事实、内容和版本条件满足时出现 CA-06；否则没有占位动作卡。保存仍经过 CA-09。

走查绑定：[COMP-T-001](26_CONVERSATIONAL_RECOVERY_COMPANION_TEST_PLAN.md#3-场景矩阵)、`COMP-T-011`、`COMP-T-019`，以及 TEST-COMP-01 §5 的运动任务。

### W-02 久坐办公后不适，R3 普通路径

1. 用户标出颈、肩或腰的主观位置，选择久坐/工作情境。
2. CA-04 的单题界面围绕当前服务端 `QuestionPlan` 显示，而非把工作情境写成病因、长期档案或自动结论。
3. 工作相关信息若是用户自报，归入“你告诉我的”；若未来实际读取获准资料，才可出现“本次经授权参考”。
4. 用户可在 CA-05 修改任何候选；修改后旧行动预览不可继续显示或保存。

走查绑定：`COMP-T-002`、`COMP-T-011`、`COMP-T-019`，以及 TEST-COMP-01 §5 的久坐办公任务。

### W-03 多位置、多感觉与多情境

1. 用户在 CA-01 添加多个位置，在 CA-02 选择训练/运动和久坐/工作两个情境。
2. 上位能力可用时，界面要求用户选择本轮分析焦点；未选时只显示跨位置的基础事实收集，绝不自动把某处或某情境设为“真正原因”。
3. CA-04/CA-05 始终把感觉与对应位置关系显示为可编辑的事实，不复制到其他 Marker。
4. 用户改动任一位置、感觉关联或情境时，屏幕说明后续问题/行动需要重新检查，并撤去旧预览。

走查绑定：`COMP-T-003`、`COMP-T-020`、`COMP-T-022`、`COMP-AC-09` 与 `COMP-AC-10`。

### W-04 仅使用本次记录，并拒绝额外资料

1. CA-02 默认显示“仅使用本次记录”；用户拒绝 Profile、历史或设备等可选来源。
2. 拒绝不阻断 CA-03 的安全确认、R3 路径中的 CA-04，或 CA-05 的事实复核。
3. 资料条和收据只显示“你已拒绝”或实际不可用状态；不得显示任何历史摘要、暗示模型仍看到了它们，或把“无资料”解释为身体状态。
4. 之后若用户改为授权，屏幕必须说明范围变化会使旧普通问题/行动预览重新检查。

走查绑定：`COMP-T-005`、`COMP-T-023`、`COMP-AC-03` 与 TEST-COMP-01 §5 的“拒绝历史资料”任务。

### W-05 R2 专业评估准备

1. 安全结果进入 R2 后，CA-07 取代 CA-04 和 CA-06；界面先呈现固定专业评估准备与升级条件。
2. 用户可以看到已知事实和未知项，并走受限的事实复核/沟通准备；不出现“先做一个动作”“再观察几天”“吃什么”或普通聊天。
3. 即使用户返回编辑或打开位置页，回到评估时仍由服务端重新选择 R2 分支，不能通过导航绕过。

走查绑定：`COMP-T-010`、`COMP-T-021`、`COMP-AC-04` 与 TEST-COMP-01 §4 的 R2 不变量。

### W-06 Provider/模型不可用：手动或降级

1. 模型不可用本身不表示用户安全、也不自动表示可保存。界面先等待服务端判定确定性安全、映射、同意和验证是否完整。
2. 条件完整且手动路径允许时，进入 CA-08A：显示“未使用 AI 分析”，用固定结构化表单收集事实并允许后续复核；没有 AI 候选、普通行动或 Provider 已运行暗示。
3. 规则、必要验证、内容、映射或兼容性任何一项无法证明时，进入 CA-08B：保留未确认草稿、公共安全入口、2D/列表、重试/稍后继续；不创建正式保存承诺，也不补写建议。
4. 网络或 Provider 恢复后，必须重新运行相应检查；旧聊天结果、旧行动预览或旧安全结果不能自动复活。

走查绑定：TEST-COMP-01 §4 第 7 条、TEST-COMP-01 §7、[QA-01 §9](11_TEST_AND_EVALUATION.md#9-degradedmode-与故障注入) 和 [SAFE-01 §10](09_SAFETY_AND_CLINICAL_CONTENT.md#10-degradedmode)。
